# Email Template Studio

Open-source MJML workspace for reusable email templates, local preview, validation, and test send workflows.

## Features

- reusable MJML templates and partials
- desktop and phone preview
- variable-driven preview rendering
- SMTP test send
- build and validate commands

## Quick Start

```bash
pnpm install
pnpm dev:studio
```

## Packages

- `@email-template-studio/core`
- `@email-template-studio/cli`
